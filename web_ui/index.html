使用说明

三步搞定

  1. 拖入文件（可一次拖多个，批量处理）
  2. 添加关键词：手输关键词，或点「手机号 / 邮箱 / 身份证号」等预设规则
  3. 先点「查找」确认命中数量，再点「开始遮罩」

遮罩原理

  • PDF：文本层按字符精确框选，并把文字从文件里真正删除（不是盖一层黑块了事）；扫描件/图表走 OCR，再按坐标打黑块
  • Word / Excel / PPT：关键词替换为 █ 实心块
  • 图片：OCR 定位后画黑块

预设规则

预设规则是正则表达式，会自动识别手机号、邮箱、身份证号、银行卡号、IP 地址、日期等格式。

也可以自己写规则：点输入框右侧的 .* 按钮切换成正则模式，再输入表达式即可。默认是普通文本匹配（区分大小写由上方开关控制）。

关于保存位置

选「浏览器下载」会弹出保存对话框（由浏览器决定存哪里，网页无法直接指定磁盘路径）；选「服务器 outputs 目录」则存在程序旁边的 outputs 文件夹，可用「打开所在文件夹」直接定位。

所有处理都在本机完成，文件不会上传到任何外部服务器。工具只监听 127.0.0.1，局域网内其他设备无法访问。
